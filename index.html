    CISCO / ASSOCIATE CERTIFICATION

    About this certification

    The Cisco Certified Network Associate (CCNA) certification covers the foundations of modern networking: network access, IP connectivity and services, security fundamentals, and automation and programmability.

    Skills covered

    • Network fundamentalsNetwork components, IP addressing, and subnetting concepts.
    • Network accessSwitching, VLANs, and wireless networking concepts.
    • IP connectivityRouting concepts and how traffic moves between networks.
    • IP servicesEssential network services and their role in connectivity.
    • Security fundamentalsAccess control and foundational network protection.
    • Automation & programmabilityFoundations of network automation and programmable networks.
